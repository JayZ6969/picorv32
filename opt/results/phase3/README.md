# Phase 3 Results

Store Phase 3 FPGA build, timing, and hardware-validation artifacts in this folder.

Per-board subfolders (for example `opt/results/phase3/icebreaker/`) include:
- `phase3_metrics.csv`
- `phase3_summary.md`
- `phase3_timing.png`
- `phase3_resources.png` (baseline vs optimized for fit profile when available)
- `phase3_baseline_compare.png`
